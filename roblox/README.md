# Астана: Жаңа өмір — версия для Roblox

3D-симулятор жизни в Астане по мотивам пиксельной игры из этого репозитория. Ты в столице с одной сумкой и 15 000 ₸: снимаешь комнату на правом берегу, работаешь курьером и бариста, учишь казахский и код, проходишь собеседование в Qazaq Soft и копишь на свою квартиру на левом берегу. Всё это — в первую астанинскую зиму с бураном.

Игра многопользовательская, интерфейс на русском и рассчитан на телефон.

## Что есть в игре

- **Город.** Правый берег: вокзал, комната у Гульнар-апай, курсы казахского, больница, библиотека, курьерская служба, базар, «Шаурма №1», кофейня. Левый берег: Байтерек с лифтом и отпечатком ладони, Хан Шатыр, Qazaq Soft, ЖК «Есіл», Нұр Әлем, Ак Орда, золотые башни. Между берегами — мост и замёрзший Есиль, по льду можно ходить.
- **Потребности.** Тепло, еда и силы. На улице мороз от −12 до −24, в буран до −33. В зданиях тепло. Если замёрзнуть или выбиться из сил, очнёшься в больнице со счётом до 5 000 ₸.
- **Деньги.** Аренда 5 000 ₸ каждое утро в 8:00. Курьер получает от 1 600 ₸ за заказ, бариста — до 3 600 ₸ за смену (с чаевыми за казахский больше), в IT платят 15 000 ₸ за задачу.
- **Учёба.** Уроки казахского и основы программирования — викторины. Для собеседования нужен третий уровень обоих навыков.
- **Покупки.** Еда, пуховик и ушанка на базаре; пуховик «Солтүстік», электросамокат и ноутбук в Хан Шатыре.
- **Цель.** Купить квартиру в ЖК «Есіл» за 1 200 000 ₸.
- **Сохранение.** Прогресс хранится в DataStore и сохраняется при выходе и каждые две минуты.

Сутки в игре длятся 12 минут. Все цены и скорости собраны в `src/shared/Config.luau`.

## Как это устроено

| Файл | Где в Roblox | Что делает |
| --- | --- | --- |
| `src/shared/Config.luau` | ReplicatedStorage.Shared | Цены, предметы, карта |
| `src/shared/Logic.luau` | ReplicatedStorage.Shared | Правила игры без обращений к Roblox |
| `src/shared/Questions.luau` | ReplicatedStorage.Shared | Вопросы по казахскому и коду |
| `src/server/World.luau` | ServerScriptService | Строит город из деталей при запуске |
| `src/server/Main.server.luau` | ServerScriptService | Время, погода, работа, магазины, сохранение |
| `src/client/Main.client.luau` | StarterPlayerScripts | Интерфейс, диалоги, метка доставки, снег |

Готовый файл места — `AstanaZhanaOmir.rbxlx`. В нём только сервисы и эти шесть скриптов: моделей нет, город строится кодом.

## Сборка и проверка

```bash
cd roblox
npm install
npm test        # компилирует скрипты настоящим Luau и проходит игру в имитации Roblox
npm run build   # пересобирает AstanaZhanaOmir.rbxlx
```

`npm test` запускает сервер и клиент в `tools/mock.luau` и проходит сценарий от вокзала до покупки квартиры. Имитация ловит ошибки логики, но не проверяет, как игра выглядит и что все имена свойств Roblox написаны верно. **В самом Roblox игра ещё ни разу не запускалась** — после первой публикации её нужно пройти на телефоне и поправить найденное.

## Публикация

В Roblox игру можно выложить двумя способами.

**С компьютера.** Открыть `AstanaZhanaOmir.rbxlx` в Roblox Studio (Windows или macOS), нажать Play для проверки, затем File → Publish to Roblox. В Game Settings → Security включить «Enable Studio Access to API Services», чтобы сохранение работало и в Studio.

**Без Studio, через Open Cloud.** Roblox принимает файл места по API, но только в уже существующее место: создать новую игру с телефона нельзя. Поэтому нужно один раз попасть за любой компьютер и создать в Studio пустую игру (File → Publish to Roblox), либо использовать место, которое уже есть в аккаунте. Дальше всё делается с телефона:

1. На create.roblox.com → Creations найти игру и записать Universe ID и Place ID.
2. В разделе Open Cloud → API Keys создать ключ с доступом `universe-places` (Write) к этой игре.
3. Отправить файл:

```bash
curl -X POST \
  "https://apis.roblox.com/universes/v1/<UNIVERSE_ID>/places/<PLACE_ID>/versions?versionType=Published" \
  -H "x-api-key: <КЛЮЧ>" \
  -H "Content-Type: application/xml" \
  --data-binary @AstanaZhanaOmir.rbxlx
```

После публикации на странице игры в Creator Dashboard нужно сделать её публичной и включить нужные устройства (телефон, планшет, компьютер).
