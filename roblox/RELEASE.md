# Публикация «Астана: Жаңа өмір» в Roblox

Игра готова к выпуску: код проверен тестами (`npm test`, 1150+ проверок), двумя раундами ревью и в Roblox Studio (все действия, работа, квартира, финал), ошибок в Output нет. Ниже — что осталось сделать руками. Всё, кроме пункта 1, делается и с телефона на create.roblox.com.

## 1. Опубликовать место (5 минут, нужен компьютер с Roblox Studio)

1. Открыть `roblox/AstanaZhanaOmir.rbxlx` в Roblox Studio.
2. Нажать **Play** и убедиться, что город построился и появилась подсказка сверху. Остановить.
3. **File → Publish to Roblox → New experience**.
   - Название: `Астана: Жаңа өмір`
   - Описание: см. раздел 4.
   - Жанр: **Roleplay & Avatar Sim** (или Life Sim, если есть).
   - Устройства: **Phone, Tablet, Computer**.
4. **Game Settings → Security → Enable Studio Access to API Services** — включить, если хотите проверять сохранение прямо в Studio (в Studio игра пишет в отдельное хранилище `AstanaZhanaOmir_v1_studio` и не трогает данные игроков).

## 2. Настройки на create.roblox.com

1. **Creations → игра → Experience Questionnaire** — обязательно до открытия игры. Честные ответы для этой игры:
   - насилие, кровь, страшилки — нет;
   - алкоголь, табак, наркотики — нет (в меню айран, чай, кофе);
   - азартные игры, платные случайные награды — нет;
   - романтика — нет;
   - реальные места: да, это город Астана (Байтерек, Хан Шатыр, Ак Орда как декорации, без политики);
   - свободный ввод текста игроками — нет (только стандартный чат Roblox);
   - покупки за Robux — нет.
   Ожидаемый рейтинг — **Minimal / All ages**.
2. **Localization → Source language: Russian**. Иначе Roblox считает исходным английский и может машинно «переводить» тексты. Тексты интерфейса уже защищены от автоперевода (`AutoLocalize = false`), но правильный исходный язык нужен для страницы игры и поиска.
3. **Configure → Audience / Privacy → Public**.
4. Иконка 512×512 и 2–3 картинки 1920×1080. Проще всего: в Studio встать на смотровой площадке Байтерека на закате (`Lighting.ClockTime = 17.5`) и сделать скриншоты; для иконки — золотой шар Байтерека крупным планом с надписью «Жаңа өмір».

## 3. Проверка после публикации (10 минут, на телефоне)

- Зайти в игру: появилась подсказка «Ты в столице…», бирюзовая метка ведёт к курьерской службе.
- Взять заказ у Даурена, донести посылку — звук монет, «+N ₸», сразу предлагают следующий заказ.
- Купить что-то на базаре, пройти урок казахского (кнопки помещаются на экране, бариста — два столбца).
- Выйти и зайти снова через пару минут: деньги на месте, показан подарок за вход.
- Если что-то не так — в Creator Dashboard → Analytics → Error Report видны ошибки скриптов с живых серверов.

## 5. Обновления после выпуска

После правок в `roblox/src`: `npm test`, затем `npm run build` и снова **File → Publish to Roblox** в Studio (или загрузка через Open Cloud — см. README). Формат сохранения уже с версией (`SAVE_VERSION = 2`) и блокировкой сессии, менять ключ хранилища не нужно.

Числа экономики (цены, зарплаты, ранги, ежедневный подарок) собраны в `src/shared/Config.luau`.
