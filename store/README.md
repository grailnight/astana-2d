# Публикация в Google Play

Здесь всё, что нужно для страницы игры в магазине, и порядок действий.
Требования Google меняются — перед каждым шагом сверяйся с подсказками в Play Console.

## Что лежит в этой папке

| Файл | Куда в Play Console |
|---|---|
| `listing.md` | Название, краткое и полное описание (русский, казахский, английский) |
| `feature-graphic.png` | Картинка для описания, 1024×500 |
| `screenshots/*.png` | Скриншоты телефона, 1080×1920, шесть штук |
| `../icons/icon-512.png` | Значок приложения, 512×512 |
| `../privacy.html` | Политика конфиденциальности — нужна публичная ссылка на неё |

## 1. Ключ загрузки

Ключ `android/astana.keystore` из репозитория — любительский, его пароль виден всем. Для магазина нужен свой ключ, который хранится **вне репозитория**. Создай его один раз:

```bash
keytool -genkeypair -v -keystore ~/keys/astana-upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

Файл ключа и пароль сохрани в надёжном месте (менеджер паролей и копия на отдельном носителе). При первой загрузке включи в консоли «Подпись приложений Play»: тогда этот ключ — только ключ загрузки, и если он потеряется, Google позволит его заменить.

## 2. Сборка AAB

Нужны JDK 17+, Android SDK и bundletool:

```bash
sdkmanager --sdk_root=$HOME/android-sdk "platforms;android-36" "build-tools;36.0.0"
```

```bash
mkdir -p $HOME/android-sdk/bundletool && curl -L -o $HOME/android-sdk/bundletool/bundletool.jar https://github.com/google/bundletool/releases/download/1.17.2/bundletool-all-1.17.2.jar
```

```bash
ASTANA_KEYSTORE=~/keys/astana-upload.jks ASTANA_KS_PASS='пароль' tools/build-apk.sh aab
```

Получится `dist/astana.aab`. Номер версии (`versionCode`) берётся из числа коммитов и должен расти с каждой загрузкой; задать вручную можно через `VERSION_CODE=…` и `VERSION_NAME=…`. Целевая версия Android — API 36; если Play попросит новее, поменяй `TARGET_API` и поставь соответствующую платформу.

## 3. Политика конфиденциальности

1. В `privacy.html` замени `[адрес электронной почты разработчика]` (три места — на трёх языках) на настоящий адрес для связи.
2. Включи GitHub Pages: Settings → Pages → Deploy from a branch → основная ветка, папка `/ (root)`.
3. Ссылка для консоли будет вида `https://<логин>.github.io/astana-2d/privacy.html`.

## 4. Анкеты в Play Console

Ответы, которые соответствуют игре сейчас:

- **Доступ к приложению:** все функции доступны без входа.
- **Реклама:** нет.
- **Безопасность данных:** приложение не собирает и не передаёт данные. Сохранения лежат только на устройстве.
- **Возрастной рейтинг (анкета IARC):** категория «Игра». Насилия, крови, пугающих сцен, азартных игр, алкоголя, табака, наркотиков и ненормативной лексики нет. Есть мягкая романтическая линия (свидания, предложение, свадьба) без откровенных сцен. Есть патрульные, которые выписывают штраф за мелкие нарушения. Общения между игроками и покупок нет.
- **Целевая аудитория:** проще всего выбрать 13+ — тогда не действуют дополнительные требования к приложениям для детей.
- **Категория:** Игры → Симуляторы. Теги: симулятор жизни, пиксельная графика, офлайн.
- **Контакты:** адрес электронной почты обязателен и виден всем на странице игры.

## 5. Порядок выпуска

1. **Внутреннее тестирование.** Загрузи `astana.aab`, добавь себя в тестировщики, установи из Play и проверь на своём телефоне (см. список ниже).
2. **Закрытое тестирование.** Для новых личных аккаунтов Google требует набрать тестировщиков (на момент написания — не меньше 12) и продержать тест 14 дней подряд. Попроси их присылать «Журнал ошибок» из настроек игры, если что-то сломается.
3. **Заявка на публикацию** и выпуск в «Рабочей версии». Первая проверка может занять до недели.

## Что проверить на телефоне перед закрытым тестом

Сборку под API 36 никто ещё не запускал на настоящем устройстве. Обязательно проверь:

- игра не залезает под вырез камеры и системные панели в портретной и альбомной ориентации;
- жест и кнопка «Назад» закрывают окна в игре, выводят из комнаты и сворачивают игру, когда закрывать нечего;
- вибрация работает;
- сохранение переживает сворачивание и перезапуск приложения;
- «Перенос сохранения» в настройках: код копируется и загружается обратно.

## Тем, кто уже играет в APK

Версия из Play подписана другим ключом и не установится поверх APK, собранного любительским ключом. Чтобы не потерять прогресс: обнови APK до версии с переносом сохранений, в настройках скопируй код, удали старое приложение, поставь игру из Play и на заставке нажми «Загрузить из кода».

## Названия в игре

Заведения и компании в игре вымышлены («Дала Кофе», «Жылдам», Steppe Digital, «Самал Плаза», «Алтын Сарай», «Шаурма №1» и другие), настоящие — только городские достопримечательности. Перед публикацией стоит поискать эти названия в 2ГИС: если в Астане есть реальное заведение с таким же именем, лучше переименовать.
